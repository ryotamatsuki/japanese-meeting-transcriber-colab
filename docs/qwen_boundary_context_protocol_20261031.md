# Qwen境界文脈比較：事前固定プロトコル

公開Studioは変更しない。PR #6の研究専用分岐。Qwen重み・Community-1・ForcedAligner・入力MP3・30秒低エネルギー境界を固定する。比較は境界前後各1秒の文脈音声を追加する条件のみ。生成トークンは時刻中点で半開の元区間へ割り当てる。文字列の類似度で発言を削除しない。隣接認識の時刻が異なる場合の欠落・重複リスクも評価する。

IngCrowd録音01はCC BY-NC 4.0の研究データであり、商用評価・未見データと呼ばない。人手参照から用語を抽出して認識へ入力しない。既存30秒条件を同一コンテナ内で再計測し、cpCER・平坦化CER・挿入/削除/置換・再試行数・GPU関数時間を比較する。

初期スクリーニングはcpCER絶対3ポイント以上改善、平坦化CER悪化なし、処理成功を必要条件とする。満たしても商用採用はしない。満たさなければ一律採用せず、追加録音へ拡張しない。単一録音に統計的優位性や商用精度を主張しない。
