# Kiroku Studio — 同一音声・A10実GPU Whisper/Qwen比較（2026-10-31）

## 判定

同一公開録音1件を使った全処理実GPU比較で、Qwenの話者付き文字誤り率は改善したが、処理時間と料金換算額は増加した。**本番匿名StudioはWhisperを維持し、Qwenへの切替えを自動承認しない。**

実行：[GitHub Actions #41162850959](https://github.com/ryotamatsuki/japanese-meeting-transcriber-colab/actions/runs/41162850959)、Modal単発研究App `kiroku-asr-paired-cost-research`。
元の数値のみを含む成果物：Artifact ID `13027918114`（期限2026-11-07）。プログラム：`modal_compare_asr_cost.py`。

## 事前に固定した比較条件

- データ：IngCrowd Japanese Themed Casual Conversation 01（CC BY-NC 4.0、非商用研究専用）、2人、同一音声675.776秒を16kHzモノラルMP3 48kbpsへ1度変換し両モデルで同一バイト列を使用。
- 入力音声SHA256：`ef62696b258a5d046422623208651c94d01a887115b887a7029dfb88d05750fe`。人手ELAN SHA256：`c59daa71d0ffa34e50b4c532d33f5c0d2a51ceaa8aea4435a68a87d924f61b32`（過去の評価と一致）。
- A10、CPU=2、メモリ8192MiB、独立関数実行、`single_use_containers=True`、`scaledown_window=2`、タイムアウト1400秒、リトライなし。
- Whisper：large-v3・beam5・日本語・VAD・単語時刻付き。
- Qwen：Qwen3-ASR-1.7B＋Qwen3-ForcedAligner-0.6B、最大30秒分割、限定再試行。
- 両方ともpyannote Community-1 exclusive、話者数2指定。最終ZIP内の話者別発言を、同一ELAN（正規化正解4166文字）に対してcpCER評価。

## 実測

| 項目 | Whisper | Qwen |
| --- | ---: | ---: |
| cpCER | 37.7100% | **26.8123%** |
| 正規化認識文字数 | 2,982 | 3,576 |
| 推定話者数 | 2 | 2 |
| パイプライン秒数 | 66.045 | 89.699 |
| GPU関数内計測秒数 | 69.550 | 100.886 |
| モデル読み込み秒数 | 2.778 | 9.290 |
| ASR・強制アラインメント処理秒数 | 38.089 | 61.469 |
| 話者分離推論秒数 | 15.059 | 14.794 |
| 関数内時間×公式単価の試験1件換算 | $0.02434 | $0.03531 |
| **録音1時間当たりの同換算額** | **$0.12966** | **$0.18808** |

- cpCERはQwenが10.8977ポイント、相対28.90%改善。今回の**1録音内の比較**であり独立録音での統計的な優劣を証明しない。
- Qwenの関数内時間は45.06%増加。録音1時間当たりの価格換算も約45%上昇。
- 公式のGPU A10 $0.000306/秒、CPU $0.0000131/コア秒、メモリ $0.00000222/GiB秒を使用し、要求CPU2、メモリ8GiBをすべて定額とする料金換算レート `$0.00034996/秒` を適用（https://modal.com/pricing）。
- **これは実際に請求・計上された料金ではない。** GPUコンテナの起動、待機、終了、CPUの計量基準、実利用地域単価、Webコンテナ、Volume、無料クレジット適用等を含めた請求書との差額は未確認。GPU関数の処理区間を課金秒数と同一視しない。
- 実際のModalアプリ別使用料は請求レポートの時間区間確定後に確認する必要がある。今回の両モデルは1つの研究Appに所属しており、App合算の費用だけでは**モデル別の請求実績を直接分離できない**。

## セキュリティ・運用の扱い

- 元音声と人手書き起こし、推論全文、HF_TOKENはGitHubに保存・公開していない。成果物は数値・音声と正解のSHA256のみ。
- 完成した単発Modal appは終了。既存匿名版 `kiroku-anonymous-studio-beta` と本番GPUモデルは変更していない。
- 実験のGitHub Actionsは一回限り実行後に検証ワークフローから撤去し、専用ワークフローは手動起動専用に変更。
- 商用の精度・コスト保証とするには、独立日本語3〜4人会議を含む5〜10件以上、1時間録音のコールド/ウォーム区別、同一の事前固定設定で追加検証する。

## 結論

**品質優先ならQwenに切り替える価値があるが、GPUコストは安くならない可能性が高い。** モデルを本番切替えする前に、多録音cpCERとモデル別請求メータ、実作業の編集時間を比較する。
