## 結論（日本語自然対話10本の基準測定）

[GitHub Actions A10 Run #41054900339](https://github.com/ryotamatsuki/ehime-kokubunsai-ai-poc/actions/runs/41054900339) で全10録音を実GPU処理し、人手ELANに対する**文字単位の話者置換最小誤り率（cpCER）**を取得。全件成功、EAF参照SHA256は従来評価の10件すべてと一致した。

| 項目 | 実測 |
|---|---:|
| 2人対話の独立録音 | 10/10処理成功 |
| cpCERの録音別中央値 | **46.8949%** |
| cpCERの全録音合算（micro） | **43.3521%** |
| cpCER録音別最小～最大 | **34.93%～48.24%** |
| 人手正解の正規化文字数 | 43,954字 |
| 予測文字数（正規化後） | 30,294字 |
| 予測／正解文字数比 | 68.92% |
| 「話者不明」として出力した文字数 | 2字 |

**従来の話者を無視して連結したCER中央値39.907%との単純な差（約7pp）を話者ラベル混同の寄与だと解釈しない。** 単一列への連結時の順序、話者ごとの連結、重複発話の取り扱いが異なるためである。cpCERは両方の誤りを組み合わせて評価する。

## 重複発話の分析上の制限と修正

最初のスコアリングでは、モデルの各発言の時刻とELAN重複区間との交差から「重複側／非重複側」に分類し、それぞれの全文をcpCER計算した。しかしELAN発言区間は重複前後をまたぐことが多く、**時刻交差が少しでもあれば発言全文をその側に割り当てる方法では、重複部分の文字列を正しく切り出せない**。一部で異常に高い参考値を生んだため、**この区分cpCERを品質判断には採用しない**。現在の評価コードは区間数・時間統計のみ残し、重複部分の文字誤り率には人手単語単位の時刻情報が必要と明記している。

この撤回は旧Artifactの実測を削除するものではなく、指標として不適切だと判断した記録である。

## 試験条件・再現可能性

- データ：[IngCrowd Japanese Themed Casual Conversation Corpus](https://huggingface.co/datasets/IngCrowd/japanese-themed-dialogue) 10録音・2話者・人手ELAN（**CC BY-NC 4.0、非商用研究評価のみ**）。
- モデル：Whisper large-v3、Community-1、Modal A10、話者数oracle=2、各音声をモノラル48kbps MP3変換。
- 指標：日本語NFKC・casefold・空白/句読点/記号除去、話者別時系列連結、一対一話者置換を全体最小化。未知話者の文も誤りとして算入。参考：[MISP Challenge 2025公式cpCER](https://mispchallenge.github.io/mispchallenge2025/task3_instructions.html)。
- コード：[scripts/evaluate_attributed_transcript.py](../scripts/evaluate_attributed_transcript.py)／[回帰テスト](../tests/test_evaluate_attributed_transcript.py)、[実験設計](v01_stage8_attributed_cer_protocol_20261030.md)。
- Artifact `12976708710`、SHA256 `7f9565b824af6173f6c9200cc9d286a33da8775e7e3b938396f5ac58452fec68`。音声・転写本文を含まず、メトリクスとEAF SHA256のみ。
- 今回は自然な2人対話であり、4人程度の行政会議の再現率・CERや編集時間短縮を直接認証するものではない。
