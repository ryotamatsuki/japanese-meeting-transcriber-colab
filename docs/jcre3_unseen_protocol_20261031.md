# J-CRe3独立ソース小規模評価：事前固定条件

既存IngCrowd10録音と別ソースの、日本語2人作業対話を取得した。これは行政会議そのものではない。会議の受入試験を満たしたと扱わず、許諾付きの新規対話評価として実行する。Qwenの学習データへの混入状況は不明であり、「モデルが未見」とは主張しない。

配布元 https://github.com/riken-grp/J-CRe3 のREADMEでデータセット全体がCC BY-SA 4.0と確認。論文のライセンスとは区別した。音声・人手転記の利用条件にクラウド処理禁止は示されておらず、指定の帰属情報とライセンス情報を保持してModalへ送る。公開リポジトリには実音声・転記全文を保存しない。

選択：公式test.idの最初の3日について各日辞書順最初のID、計3本。ASR結果を見る前に固定した。ELAN転記は各録音のhh付きファイルの日付が最も新しい版を選ぶ。注記の(P)、<H>を除外し、(F 本文)、(R 本文)は本文を残す。不明な注記は黙って削除せず拒否する。

Boxの原WAVのダウンロードは作業環境への移送に失敗した。一方、公式配布ページのプレビューMP3を取得できた。これは44.1kHzステレオの再圧縮音声であり、原音声評価と呼ばない。音声・参照のSHA-256とソースのコミットをmanifestへ固定し、パッケージ全体のハッシュとサイズも評価コードへ固定する。別の転載データへ置換しない。

比較モデルを変更せず、Qwen3-ASR-1.7B / ForcedAligner-0.6B / Community-1 exclusive、期待話者2、30秒低エネルギー境界、最大生成512、最大2段階リトライを維持する。context入力・選択的再認識の候補選びや参照を用いる音声切断は行わない。

末尾無音で「文字起こしが録音長の80%へ到達しない」と失敗する可能性があるため、研究呼出に限りCommunity-1が検出した最終発話時刻をカバレッジ検査へ明示する。人手参照の終了時刻をASR処理に使用しない。既定呼出の挙動は維持し、回帰試験を追加する。

費用：2026-10-31のModal画面で残クレジット$24.88、Usage limit $30を確認。上限は変更しない。専用一時アプリkiroku-jcre3-unseen-pilot-20261031-01、専用入力Volume、A10最大1コンテナ、GPU関数600秒・自動リトライ0、一度のみ実行。受付CPU関数には既存モデルVolume・HF秘密情報をマウントしない。PUTは固定の公開データパッケージと同じハッシュ・サイズだけ受理し、ダウンロードやGPU起動APIは提供しない。評価前の待機はGitHub ActionsのCPU側で行う。完了時に一時アプリを停止し、入力ZIPを削除する。

評価は録音別cpCER、平坦化CER、IDS、正常終了、時間を数値のみで報告する。3録音の中央値と正規化文字数で重み付けたmicro cpCERを区別する。商用認定は行わない。独立ソースでも、台本に基づく2話者の近接マイク音声から3〜4人の行政会議へ一般化しない。

今回見送った主な候補：J-MeetEvalは合成テキストで音声なし。MeconAudioは会議録の1人読み上げで、音声の商用利用は別途許諾。MagicDataTechはApache-2.0タグと本文の非商用条件が矛盾するため採用しない。HTHプレビューのLICENSEは0バイトであり、フルセットの有償商用条件からプレビューの許諾を推定しない。Qlean日本語3者会議は申請・契約条件があり、無許諾では取得しない。

初回受付はコンテナ起動時のローカル用image factory import欠落で失敗し、入力未到着のためGPUは起動していない。modal.is_local()でクライアント専用importを制限し、依存モジュールなしのremote import回帰試験を追加。再試行のデプロイも前試行の後片付けと同じconcurrency groupへ入れ、旧試行の停止が新試行に影響しないよう直列化する。数値全体はartifactに加え公開ログへも出せるようにし、音声・本文は出力しない。
