# Stage v0.1-10 — 日本語ASRモデル・ビーム幅比較のA10実証

日付：2026-10-30。**現行ベータ設定は変更しない。Release No-Go。**

## 実施概要

[Stage10 A10 GPU 9 trials Run 41058590441](https://github.com/ryotamatsuki/ehime-kokubunsai-ai-poc/actions/runs/41058590441)はすべて完走し、計9件の推論を独立した同一音声・正解で評価した。対象はIngCrowdの公開日本語自然2人対話01/05/08、CC BY-NC 4.0（非商用研究用途）。16kHzモノラル48kbps MP3、A10 GPU、各録音ごとにWhisper ASRのみ（話者分離OFF）で試した。

モデル切替えを既定アプリへ混入させないため、Configで`asr_model='large-v3'`をデフォルトに維持し、他モデル・beam 8は`quality_experiment=True`の場合のみ有効とした。実験CLIは`modal_app.py`、元の`beta_modal.py`は変更なし。

- beam8は3件中2件改善、1件悪化、中央値では−0.471ポイントと小幅。実用リリース目標15%への橋渡しには不十分。
- turboは3件中1件改善、2件悪化、中央値では+1.973ポイント悪化。一方ASR推論は**約2.60倍高速**。処理速度優先の別モード候補であり、デフォルトの精度改善案として不採用。
- 元データの音声・人手逐語・推論文字列をGitHubへ保存せず、数値・EAFハッシュだけを保全。
- 研究数値は**正規化・時刻順連結CER**。2人の重複発話で文の前後が入れ替わると増えるため、単一話者音声のCER、cpCERとは区別。
- 全録音で同じパイプライン・言語指定・句読点除去・音声品質条件を守った。しかし3録音のみの実験であり一般化は不可。

- **Qwen3-ASR-1.7B**は別の隔離環境で2録音の追加研究として評価する。Qwenの出力は話者付き原稿ではなく、現行UI向けの時刻・話者割当てが別途必要。対応する実測結果がない時点では採否を確定しない。

## 判断

Stage10の初期3方式比較だけでは既定モデルの精度改善を正当化できない。**モデルを切り替えず、beam5のlarge-v3を維持**する。今後、候補が基準を有意に改善する場合のみ全10録音およびcpCER、速度、GPU費用、時刻精度の比較へ進める。

同じ実験の設計基準：[v01_stage9_10_experiment_protocol_20261030.md](v01_stage9_10_experiment_protocol_20261030.md)。関連：[Stage8 cpCER監査](v01_stage8_attributed_transcript_results_20261030.md)。

## Qwen3-ASR-1.7B：長時間音声の分割処理を実装して再評価

- [モデル一次資料](https://huggingface.co/Qwen/Qwen3-ASR-1.7B)、[qwen-asrパッケージ](https://github.com/QwenLM/Qwen3-ASR)、モデルはApache-2.0。研究データはIngCrowd CC BY-NC 4.0（非商用）。
- **初回 Run #41059676823 は無効データ**。Qwen公式SDKの通常`transcribe`はデフォルトで最大1,200秒を1塊にして推論できる一方、最初の実験は`max_new_tokens=256`のまま約11分の全音声を投入したため、1録音400文字未満で途中打切りとなった。記録された高いCERをモデルの真の認識性能と判断してはならない。
- 研究コード`modal_stage10_qwen.py`を修正し、エネルギーが低い境界で**最大30秒**に分割、各区間を`max_new_tokens=512`で認識後、順に結合。生音声・認識全文は保存せず、数値評価だけ収集。
- [修正後 Run #41060548259](https://github.com/ryotamatsuki/ehime-kokubunsai-ai-poc/actions/runs/41060548259)：**2/2完走**。ELAN参照ハッシュは先行Whisper評価と一致。
