- 10/10録音でQwenのCERが改善。差のペア別中央値は8.94ポイント改善。
- 全件合算（micro）CER：Whisper 38.23%、Qwen 28.56%。
- 共通の人手ELAN正規化参照：43,954字。参照EAF SHA256と正規化参照文字数は全10件一致。
- 認識文字数合計：Whisper 30,296字、Qwen 35,394字。これは欠落文字数そのものではない。
- Qwen3-ASR-1.7Bは音声を最大30秒に分割し、最大512生成トークン/区間。旧初回一括推論は不適切な生成トークン上限で失敗していたため採点から除外。
- 10録音いずれも2話者の自然な対話。コーパスはIngCrowd Japanese themed dialogue、**CC BY-NC 4.0、非商用評価専用**。
- **指標は時刻順に平坦化した正規化CERであり、最終話者付きcpCERではない。** 日本語2～4人行政会議の精度や15%以下の受入基準を認証するものではない。
- 独立したGPU実行の結果を共通正解で比較した。厳密な同時ペア推論・モデルロード・コスト公平比較ではない。

### Stage 10のその他の候補

- large-v3 beam8はbeam5と比べ3録音中2録音でCER改善、1録音で悪化。CER中央値40.87%→40.40%と改善は小さいため見送り。
- large-v3-turboは3録音の合計ASR推論時間で約2.60倍高速だが、CER中央値は40.87%→42.85%と悪化。精度改善としては不採用。

### Stage 9：重複発話の音源分離

- 2つの短い人手オラクル選択重複発話区間で、SepFormerの音源分離は1件だけcpCER改善、1件変化なし。
- 実際の各話者独立音声を別々に認識すると両件で大幅改善するが、単一マイク音源から自動で得られるものではない。
- 英語WSJ向けSepFormerを日本語Webアプリへ自動採用する根拠は不足。**Stage 9候補は不採用**。元の排他的話者割当てとStage 7の要確認UIを維持。
- 証拠：[Stage9 A10 Run 41060111462](https://github.com/ryotamatsuki/ehime-kokubunsai-ai-poc/actions/runs/41060111462)。

## 次段階への移行条件

Qwenを現行のWebアプリへ入れる前に、(1)単語・文の時刻付与、(2)Community-1話者帰属との統合と最終cpCERの10録音比較、(3)60分音声のWeb経由E2E、(4)誤認識・重複時の誤文追加、(5)推論時間・GPU課金、(6)セキュリティ・データ削除をそれぞれ検証する。良好でない場合はWhisperへ切戻せるよう既定処理を維持する。
