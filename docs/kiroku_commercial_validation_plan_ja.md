# 商用判定に必要な未完了の評価

現在の研究結果は商用判定を満たさない。単一の開発録音で候補を改善しても、未見の会議・複数話者・利用者の修正負担について結論は出せない。

## 評価データの準備

- 許諾範囲を確認した、開発に使用していない日本語会議の原音声と人手参照を用意する。行政用語、数字・金額、2人および3〜4人、重複発話、遠距離収録を含める。
- 調整用と最終評価用を録音・話者単位で分ける。同じ会議の別区間を独立録音として数えない。学習データ混入の有無が不明なら、その不明点を記録する。
- 原音声と参照全文は非公開領域で保持する。公開PRには匿名の録音ID、ハッシュ、数値のみを載せる。contextは事前の会議資料・利用者の用語から作り、評価参照から正解語を抽出しない。
- IngCrowdの既存10録音は非商用条件付きの開発研究データであり、商用用途の許諾確認や独立評価の代わりにしない。

## 測定と判定

1. 認識本文・話者・時刻を分けて診断する。cpCERとCERに加え、数字・固有名詞の正解率、実際の欠落箇所、重複発話で回収できた本文を原音声と照合する。
2. 熟練度の異なる利用者が、同一デザインのStudioで原音声を聞き、修正してZIPを完成させる。実測の作業時間、残存誤り、数字・金額の重大誤り、確認候補の適合率を測る。開発者の模擬操作を人間の効果測定として扱わない。
3. 候補を確認する群と通常の全文確認を行う群では、同じ人が同じ録音を繰り返す学習効果を避け、順序を入れ替える。単に確認候補を15%へ制限しただけでは、品質や時間の改善としない。
4. 最終精度、許容修正時間、許容費用の受入値は用途に応じて事前に合意する。現在の「cpCER 3ポイント以上改善、CER悪化なし」は候補の初期スクリーニング基準であり、商用受入基準ではない。
5. 数値改善と同時に、保存・編集・ZIP整合性と利用者間分離の実環境試験を再実行する。少数の正常終了やCPUテスト数から商用の故障率を推定しない。
